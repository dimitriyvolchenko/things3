# Planner Room — самостоятельная версия без папок

Все файлы этого архива уже находятся **на одном уровне**. Распакуйте ZIP, выделите **все 29 файлов сразу** и загрузите их в корень нового репозитория GitHub через **Add file → Upload files → Commit changes**. Не загружайте сам ZIP, и не создавайте папку `room` или `assets`.

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**. Адрес будет `https://USERNAME.github.io/REPOSITORY/`. Дождитесь публикации.

Чтобы перенести прогресс, в старом Planner выполните Export/Backup JSON, затем в Planner Room используйте **Import a plan**. Перед импортом сохраните резервную копию данных нового приложения.

Для отдельной синхронизации используйте имя нового репозитория и отдельный файл **`progress-room.json`**. Этот файл приложение создаст при первом успешном сохранении через GitHub, если у токена есть разрешение **Contents: Read and write** на новый репозиторий. Токен никому не отправляйте и не добавляйте в GitHub-файлы.

⚠️ Данный ZIP **не содержит** `progress.json` или `progress-room.json`; существующие файлы прогресса другого Planner не затрагиваются.

Вместе с `index.html` обязательно загрузите `room.css`, `sw.js`, `manifest.webmanifest`, `refresh.html` и все PNG/SVG-файлы: ссылки в приложении и кэш Service Worker специально исправлены под плоскую структуру.
